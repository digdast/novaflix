# Contributing to NovaFlix

We welcome contributions from developers, designers, and homelab enthusiasts worldwide!

## How to Get Started
1. **Fork the Repository** on GitHub.
2. **Clone your Fork**:
   ```bash
   git checkout -b feature/transcoder-tuning
   ```
3. **Install Dependencies**:
   ```bash
   pip install -r requirements.txt
   ```
4. **Run the Test Suite**:
   ```bash
   python test_novaflix.py
   ```
5. **Submit a Pull Request**.
